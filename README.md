# Ante-Possessive Lives in the Americas

A public-facing digital humanities project on dispossession in early New England and Yucatán.

This repository contains the static HTML, CSS, JavaScript, and image assets for the current project site. The project develops from research directed by Professor David Kazanjian and the 2026 Penn Undergraduate Research Mentoring Program (PURM) team, while building on earlier collaborative digital work.

## Site structure

- `index.html` — project landing page
- `theory.html` — Theory & Method
- `adam.html` — Adam Saffin case study
- `juan-patricio.html` — Juan Patricio case study
- `bibliography.html` — Sources & Bibliography
- `credits.html` — About & Credits
- `styles.css` — shared design system
- `script.js` — shared interaction logic

## Publishing

The site is designed to run as a static site and can be published directly with GitHub Pages.
