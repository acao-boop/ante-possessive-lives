# Changelog

This file records public releases. Earlier working builds and design experiments are preserved in the repository’s legacy archive rather than listed individually here.

## 1.0.0 — August 20, 2026

First formal public release, corresponding to internal build V26.4.

### Added

- A responsive static site replacing the project’s ArcGIS-dependent presentation layer
- A unified project index, navigation system, bibliography, About page, and vocabulary apparatus
- Four responsive Theory & Method figures
- Consistent figure labels, captions, source notes, and alternate-access notices
- Adam Saffin and Juan Patricio Knight Lab StoryMap embeds
- A historical and contemporary map comparison slider for the Juan Patricio case
- Mobile layouts for the landing page, internal navigation, diagrams, maps, and interactive elements
- Repository maintenance, archival migration, and asset-credit documentation

### Revised

- Theory prose for clarity, cohesion, and accessibility
- Adam Saffin and Juan Patricio prose while preserving the original case-study structures and authorship
- Site-wide image credit, citation, editorial-note, and contributor language
- Professor David Kazanjian’s portrait and institutional profile link
- Figure I sequencing, now communicated by aligned Roman numerals and spatial order without directional arrows
- Site-wide divider treatment and production CSS, removing stacked rules and unused component styles
- Professor Kazanjian’s marked About-page revisions, including the Stanford collaborators heading and Stanford Humanities Center acknowledgment

### Validated

- Local assets and internal anchors
- External-link safety
- HTML parsing
- CSS structure
- JavaScript syntax
- Responsive behavior at common desktop, tablet, and mobile widths
